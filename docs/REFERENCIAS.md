# Referências de implementação

Fontes técnicas primárias consultadas para a arquitetura e distribuição. Não documentam endpoints administrativos específicos da instalação Servip2P.

- FastAPI — containers: https://fastapi.tiangolo.com/deployment/docker/
- FastAPI — WebSockets: https://fastapi.tiangolo.com/advanced/websockets/
- HTTPX — clientes e cookies: https://www.python-httpx.org/advanced/clients/
- Playwright Python — biblioteca e empacotamento: https://playwright.dev/python/docs/library
- Playwright Python — autenticação: https://playwright.dev/python/docs/auth
- PyInstaller — modo de operação e build por plataforma: https://pyinstaller.org/en/stable/operating-mode.html

Referência fornecida pelo usuário, sem conteúdo de requisições extraído nesta entrega:
https://www.postman.com/winter-eclipse-734330/kofficepanel-public-api/collection/4x6ftu6/kofficepanel-public-api
