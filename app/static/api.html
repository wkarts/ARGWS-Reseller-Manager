CONTRATO DA SUA APLICAÇÃO

Integração com controle

Os endpoints abaixo pertencem ao Reseller Manager, não ao kOfficePanel. Cada operação remota depende do perfil aprovado para sua conexão.

Autenticação

Use Authorization: Bearer SEU_TOKEN_DESTA_API. A credencial do fornecedor fica protegida na conexão. Alterações exigem confirmed: true e Idempotency-Key.

Fluxo mínimo

Crie uma conexão → inspecione o login ou importe a coleção → valide e salve o perfil → conecte → consulte clientes → execute uma operação autorizada.

WebSocket
Conecte a /ws/events e envie em até 5 segundos:
{"token":"SEU_TOKEN_DESTA_API","after":0}
O token não deve ser colocado na URL. Use o último seq recebido para retomar eventos; uma chave revogada encerra a conexão.
Como interpretar o resultado
202 queued registra um trabalho; não confirma execução. Consulte /api/v1/operations/{id}. succeeded indica que a resposta satisfez a regra aprovada do perfil; não é uma homologação independente do fornecedor. reconciliation_required exige conferir no painel antes de enviar outra alteração.

Ações do conector
Em /queries/{action}, use as ações de leitura. Em /operations/{action}, use as de alteração. Os parâmetros reais vêm do contrato da conexão, não desta documentação.
